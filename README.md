## Core Mission: Global AI Access & Purchasing Power Parity

Artificial Intelligence is the strongest cognitive leverage multiplier in modern engineering. Concentrating frontier agentic capabilities exclusively behind high-income advisory rates widens global technical inequality. Talent is distributed worldwide, while currency strength and capital access are not.

Every flagship program and individual service pick in this practice is indexed across **Six Global Purchasing Power Parity (PPP) Tiers**, providing automatic 25%, 50%, and 75% discounts plus custom subsidized micro-rates for crisis-affected and under-resourced builders across 195 countries.

## Deterministic SSOT Build & Test Pipeline

All commercial facts live exclusively in [`data/*.json`](file:///home/thomas/GitHub.io/thomascherickal.github.io/data) (validated by [`data/schema/*.schema.json`](file:///home/thomas/GitHub.io/thomascherickal.github.io/data/schema)) and propagate outward in one direction into HTML pages, `llms.txt`, `README.md`, and `assets/data/site-data.json`.

### Key Commands
```bash
# 1. Validate all data/*.json schemas and cross-file invariants
python3 python/ssot/validate.py

# 2. Render deterministic SSOT markers and verify zero drift
python3 python/ssot/render.py
python3 python/ssot/render.py --check

# 3. Export client-side calculator data (assets/data/site-data.json)
python3 python/ssot/export_site_data.py

# 4. Inline shared header.html and footer.html across all standalone pages
python3 python/build_components.py

# 5. Run full Python + JavaScript + HTML UI test suites (with SHA-256 data/ immutability guard)
python3 python/run_tests.py

# 6. Pre-commit synchronization & link verification
python3 python/sync_schemas.py
python3 python/md_html_sync.py
python3 python/check_links.py
```
