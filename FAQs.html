Mandate #1
FAQ #01 — Revision Policy

How many revisions till satisfied?

Infinite revisions. We iterate continuously on every draft, technical guide, and code repository until your team is 100% satisfied with prose clarity, technical accuracy, and execution benchmarks.

Mandate #2
FAQ #02 — Billing & Terms

How are the payments handled?

Payments are handled by milestones, with every milestone having equal weightage on the final product. Whether split 50/50 for articles or 33/33/34 across multi-part suites, every phase carries equal weight.

Legal & IP
FAQ #03 — IP Rights

Who owns the intellectual property and code repositories?

You retain 100% full IP ownership and copyright upon completion. All technical guides, notebooks, and sample code are delivered directly under your organization's open-source or proprietary licensing terms.

Quality Assurance
FAQ #04 — Code Verification

How is code execution and benchmark accuracy verified?

Every code snippet, API request, PyTorch pipeline, and Qiskit quantum circuit is manually executed and verified in isolated containers or live hardware simulators prior to publication. No unverified boilerplate.

Global Equity
FAQ #05 — Purchasing Power Parity

What is Purchasing Power Parity (PPP) / Country Parity Pricing?

PPP pricing ensures equal access for engineering teams globally. Clients in Tier 2 Developing Nations get 25% off (75% price) and Tier 3 Least Developed Nations get 50% off (50% price) based on World Bank indices.

Startups
FAQ #06 — Startup Discounts

Is there a special discount for early-stage startups?

Yes! Pre-Seed and Seed-stage startups receive a prominent 50% discount across all technical content packages to accelerate developer acquisition during crucial launch windows.

Tech Stacks
FAQ #07 — Supported Technologies

What technology stacks and frameworks do you cover?

Generative AI (PyTorch, vLLM, Ollama, LangChain, LlamaIndex, Claude, Gemini APIs), Quantum Computing (IBM Qiskit, PennyLane, Cirq), and Core Systems (Python, Rust, Go, TypeScript).

Delivery
FAQ #08 — Turnaround Times

What is the typical turnaround time for a deliverable?

Short technical articles take 3–5 business days; standard deep dives take 5–8 business days; full developer documentation suites take 14–21 business days.

Confidentiality
FAQ #09 — NDAs & Security

Do you sign Non-Disclosure Agreements (NDAs)?

Yes, absolutely. Standard mutual NDAs are executed prior to examining unreleased API endpoints, proprietary SDKs, or pre-launch model architecture documentation.

Information Architecture
FAQ #10 — Multi-Audience Content

Can you write for both developers and executive leaders?

Yes. Using the Diátaxis framework, content is structured with modular sections: quickstarts for busy engineers, benchmark deep dives for researchers, and executive summaries for decision-makers.

Formats
FAQ #11 — Deliverable Formats

In what file formats do you deliver content?

Clean Markdown (`.md`), MDX, Jupyter Notebooks (`.ipynb`), executable Python/Qiskit scripts, OpenAPI/Swagger JSON specs, and direct GitHub Pull Requests to your repository.

AI Methodology
FAQ #12 — AI Acceleration

How does AI acceleration work with 100% human verification?

Frontier AI tools accelerate research aggregation and initial outline drafting. Every line of prose and code is then hand-written, manually tested, and line-by-line verified by Thomas Cherickal.

Training
FAQ #13 — Remote Enablement

What is included in Remote Engineering Team Training?

2-hour interactive enablement workshops covering Generative AI architecture, local LLM inference deployment, and Post-Quantum Cryptography (PQC) transition risks, backed by hands-on notebooks.

Partnerships
FAQ #14 — Retainers

Do you offer monthly content partner retainers?

Yes. Monthly retainer partnerships provide dedicated sprint capacity for technical articles, changelogs, SDK update guides, and continuous documentation maintenance.

Support
FAQ #15 — Post-Launch Maintenance

What happens if an API version changes shortly after delivery?

Minor code snippet updates and API breaking change patches are included free for 60 days post-launch under our commitment to long-term content accuracy.

Onboarding
FAQ #16 — Project Commencement

How do we get started on a project brief?

Submit your requirements via the brief form on services.html#contact. We return a clear milestone scope proposal within 24 hours.

Benchmarks
FAQ #17 — Reproducible Benchmarking

Can you author reproducible benchmark comparison reports?

Yes. Standalone benchmarking passes include a dedicated GitHub repository with reproducible scripts for throughput, latency, memory utilization, and accuracy metrics.

Quantum Validation
FAQ #18 — Quantum Simulator vs Hardware

How are quantum algorithms verified on hardware?

Quantum circuits are validated first on statevector simulators (Qiskit Aer / PennyLane), followed by noisy simulation models and execution on IBM Quantum hardware backend channels.

Localization
FAQ #19 — International Content

Do you support multi-language documentation translation?

Primary content is authored in clear US English, structured semantically with clean HTML/Markdown for seamless translation via automated i18n pipelines.

Payments
FAQ #20 — Payment Channels

What payment methods do you accept internationally?

We accept International Wire Transfer (SWIFT / ACH), Stripe invoices, Wise, PayPal, and major Stablecoins (USDC / USDT) for seamless global settlement.
