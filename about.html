Workflow Disclosure

How This Actually Gets Made

The AI-Proof Advantage: roughly half AI-accelerated for drafting speed, half hand-verified for absolute technical truth.

The AI-Proof Advantage

Technical writing hasn't been automated by AI — it's been split in two. AI can now draft structured reference docs, boilerplate, and first passes from a spec almost instantly. What it cannot do is verify that what it just wrote is true — that the API call actually returns what the doc says, that the quantum circuit actually produces the claimed output, that the benchmark numbers are real and not plausible-sounding fabrication.

That verification step is the job now. It requires someone who can run the code, execute the circuit, and check the claim against a live system — not someone reformatting a draft. That's the actual service on offer here: content where every code sample has been executed, and every quantum circuit has been run in a simulator or on real hardware, before publication. A model publishing under its own name carries no such accountability. I do.

⚡ Automated with AI (Roughly 50%)

AI accelerates execution speed without touching technical truth:

  • First-draft generation from a brief, spec, or transcript
  • Research aggregation and source discovery across documentation, changelogs, and papers
  • Structural drafting — headings, section flow, Diátaxis-pattern scaffolding
  • Style, terminology, and consistency linting against a house style guide
  • Format conversion — Markdown to MDX/HTML, citation formatting, table generation

✓ Verified by Hand (The Mandatory Half)

Hand-checked against live code, simulators, and primary sources:

  • Executing every code sample against the live API, SDK, or local environment it documents
  • Running every quantum circuit in a Qiskit Aer simulator or on real quantum hardware and checking the output against the claim in the text
  • Cross-checking every benchmark, statistic, or comparative figure against its original source before it's cited
  • Technical accuracy review against current product behaviour — catching the gap between what a spec says and what the system actually does
  • Final judgment calls on structure, emphasis, and what's worth explaining at all — the editorial decisions a model has no stake in getting right

"Roughly half of this workflow is Generative AI-accelerated. All of it is real. The AI writes faster; it doesn't get to decide what's true — that part stays manual, on every project, without exception."

Verification & Execution Methodology

  • Code samples are run in real Python REPLs or Cargo test sandboxes before appearing in deliverables — never eyeballed for plausibility.
  • Quantum examples are executed against Qiskit's Aer simulator (or real IBM Quantum hardware) and actual output figures get published.
  • Cited statistics and comparative benchmarks are traced directly to primary papers or documentation sources.
  • The execution discipline runs on pytest, cargo test, Jupyter, Qiskit Aer, and sandboxed containers — verified engineering, not marketing language.
