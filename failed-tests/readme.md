# Failed Tests Reports Directory

All failed-test reports generated by the repository test runners are stored exclusively in this directory:

- `failed-python-tests.md` - Generated by `python/run_tests.py` when Python unit tests fail.
- `failed-html-tests.md` - Generated by `python/run_html_tests.py` when HTML UI tests fail.
- `failed-pricing-tests.md` - Generated by `pricing-tests.js` (`tests/js/test_helpers.js`) when JavaScript tests fail.

Each runner automatically deletes its corresponding report file in `failed-tests/` as soon as its test suite passes 100%.
