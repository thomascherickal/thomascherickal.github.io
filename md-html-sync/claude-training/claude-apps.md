## Table of Contents

Traditional AI tool calls were built for models to read, not humans to operate - returning static walls of raw text or JSON blobs that force users to jump across browser tabs to filter charts, rearrange project timelines, or edit documents. Claude Apps - powered by the open MCP Apps specification - close that gap by allowing Model Context Protocol servers to render live, bidirectional interactive user interfaces directly inside your conversation thread, split-screen workspace, or standalone desktop window.
