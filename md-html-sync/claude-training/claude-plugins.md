## Table of Contents

Copying loose prompt files, hook scripts, and MCP configs from one laptop to another works for a single developer, but it breaks down fast across a 20-person engineering team. Claude Plugins solve distribution by bundling skills, MCP servers, slash commands, rules, and lifecycle hooks into a single versioned package that installs, updates, and disables cleanly as one unit.
