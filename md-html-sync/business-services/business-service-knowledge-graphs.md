## Keeping Graphs Accurate Over Time and Team Deliverables

Every edge in a production knowledge graph must carry provenance metadata: which source document created it, when it was extracted, and when it expires. When a contract is renewed or an employee changes teams, incremental ingestion updates only the affected edges instead of rebuilding the entire graph from scratch.

- Domain Ontology & Entity Resolver: Clean, business-focused graph schema with automated alias deduplication.
- Hybrid GraphRAG Service: Live retrieval API combining Cypher/SQL graph traversal with vector text grounding.
- Multi-Hop Evaluation Benchmark: Automated test suite comparing GraphRAG accuracy and token usage against plain RAG.
- Incremental Sync Pipeline: Event-driven graph updates with full source provenance and audit trails.
