## Safe Agentic Coding Workflows and Team Deliverables

Unchecked AI coding agents can create massive, unreviewable pull requests that hide security flaws or subtly break unrelated modules. We train engineering teams to enforce small, atomic diffs, automated static analysis, and regression evaluations inspired by Google Engineering Practices for code review. Every agentic coding session runs on an isolated branch, executes the full local test suite, and produces a concise change summary for human reviewers.

- Typed AI Feature Module: Production Python service using strict Pydantic schemas, retries, and fallback handling.
- Hybrid RAG Starter Pipeline: Structure-aware chunking, hybrid search, citation verification, and automated evaluation script.
- Automated TDD Templates: Repeatable prompt and pytest workflows for legacy onboarding and new feature development.
- Team AI Coding Standards: Shared repository rules, review checklists, and CI quality gates for agentic pull requests.
