## Service
 Overview & Scope

- Coding Agent Fluency: Working with Claude Code in the terminal and the IDE, from a first
 session through plan mode, subagents and background agents.
- AI-Assisted Test-Driven Development (TDD): Red-green-refactor with an agent: tests
 written from the spec first, then code until pytest or cargo test passes.
- MCP Server Development: Building, testing and debugging custom MCP servers in Python and
 Rust.
- Agents in CI/CD: Headless Claude Code runs in CI, the Claude GitHub app for pull request
 review, and hooks that run formatters and tests after every edit.

 project knowledge they need in large codebases.
