## Three-Tier Markdown Memory Architecture

Dumping everything into one giant memory file quickly ruins assistant quality. As the file grows, the model gets distracted by outdated notes, spends extra tokens reading irrelevant history, and starts contradicting itself. A three-tier Markdown memory architecture solves this by separating stable rules from active work and short-term logs.

Tier 1 is your Core Profile file, usually under two hundred lines. It holds your communication style, formatting rules, preferred tools, and hard boundaries. It changes rarely, perhaps once a month, and is loaded at the start of every session. Tier 2 consists of Active Project Briefs, one short Markdown file per current goal or client engagement. Your assistant only loads the specific project file relevant to the task at hand, keeping context sharp and focused.

Tier 3 is your Rolling Daily Log. At the end of each working day, the assistant appends a five-line summary of completed tasks, open questions, and newly discovered preferences. Once a week, a short consolidation routine promotes any durable lesson from Tier 3 up into Tier 1 or Tier 2, and archives old daily logs. This simple three-tier rhythm mirrors how effective human notebooks work and keeps your assistant fast, accurate, and easy to audit.
